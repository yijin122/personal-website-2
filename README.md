# Hedy

A personal portfolio for recruiters. The pages follow a documented record of operations research, data science, and visual work: Cornell ORIE scheduling, ride-hailing pricing, retail placement, FDNY ambulance posting, OHCA volunteer allocation, intelligent scissors, retrieval research, teaching, and the Chinese Drama Society.

The site is presented under the name **Hedy**.

## Run locally

```bash
npm install
npm run dev
```

The dev server binds to `0.0.0.0:4317`. Open [http://127.0.0.1:4317](http://127.0.0.1:4317).

## Pages

- `/` — introduction, reported results, and case-study rows
- `/work` — searchable case studies
- `/work/[slug]` — a study with an interactive figure
- `/experience` — technical roles, teaching, and leadership
- `/about` — degree, coursework, and skills

Figures that you can drag are schematics. Reported results stay labeled as reported. Values that were not in the notes are labeled illustrative.
